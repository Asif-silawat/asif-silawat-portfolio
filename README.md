# Asif Silawat Portfolio

Modern animated creative portfolio built with Next.js, React, TypeScript, CSS and Framer Motion.

## Run locally

1. Install Node.js 20.9+.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Add your real work

Replace the project placeholders in `public/projects/` and update `data/projects.ts`.

For real project images, you can also change the project detail pages to use `next/image`.

## Deploy to Vercel

Push the project to GitHub, import the repository into Vercel, and deploy with the default Next.js settings.

## Personalize

- Change email in `app/page.tsx`
- Change social URLs in `app/page.tsx`
- Replace project data in `data/projects.ts`
- Add your resume as `public/resume.pdf`
- Replace gradient previews with your actual images
